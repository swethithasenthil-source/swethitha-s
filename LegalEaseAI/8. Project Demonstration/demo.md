# 8. Project Demonstration

## Application Demonstration

The demonstration shows the complete workflow of LegalEaseAI.

## Step 1 – Open Application

The user opens the LegalEaseAI application.

## Step 2 – Provide Legal Content

The user enters or uploads the required legal document.

## Step 3 – Submit for Analysis

The user submits the document for AI-based analysis.

## Step 4 – AI Processing

The backend processes the request and communicates with
the AI service.

## Step 5 – View Result

The application displays the generated summary and
simplified explanation.

## Step 6 – Ask Questions

The user can ask questions related to the provided content.

## Step 7 – Export

The user can generate and download the required output format.
